# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 修复来源文件，重新上传并执行。历史批次保留供复核。
4. 对账无差异且无坏行时可签发。对仍有差异的版本可填写暂缓意见。
5. 导出复核证据并保存于交接记录。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。

## 费率更正（回溯月初）

1. 在工作台选择「费率更正」模式，挑选费率档案（`corrected`）或上传费率 JSON，先点「更正预览」。
2. 查看分组的分段账单：每段含键、分钟、费率、金额；暂停只扣一次，免计分钟跨段只用一次。
3. 出现 `RATE_INTERVAL_MISSING` 或 `INVOICE_MISMATCH` 的分组为挡签，批次不可签发，按阻断记录核对来源或费率表。
4. 全部分组通过后「执行更正批次」，再在批次复核里签发；已签发的历史批次保持原费率不变，更正批次的 `lineage` 保留原金额与差额供追责。
5. 同源数据配合同一费率表重跑只返回原批次，不会覆盖或丢失记录；不同费率表生成独立批次。
